# CoRoLab UoM

Currently hosted at https://corolab.github.io

## Running locally for debugging

Powered by [jekyll](https://jekyllrb.com/), your friend is:
```bash
bundle exec jekyll serve
```

## Please do not upload the following folder and file
Please do not upload the `_site` folder, which should be auto-generated by GitHub pages, nor the `Gemfile.lock` file.

## File and folder description

### README.md
The first line of this file, which is the file you are reading, becomes the `.html` `<head>` `<title>` (what is seen on the browser's tab description).

### _config.yml
This is another important file. It contains:
- Metadata that is important for SEO
- Some basic color settings
- Links to your social media, where you can add new links for free and will be rendered nicely

### _includes
Includes plain `.html` files which should be rather static, but can be modified freely.
- [members.html](/_includes/members.html): This is the only file you will probably be editing manually. Once [#3](https://github.com/corolab/corolab.github.io/issues/3) is done, the workflow will change and this description should be updated.

### img
This is the place to upload images. You'll probably be using [img/portfolio](/img/portfolio) most, to upload `member` profile images.

## Final comments
All the files and folders that have not previously been mentioned here should probably be maintained static. If there are any doubts or comments... please file an [issue](https://github.com/corolab/corolab.github.io/issues)!
